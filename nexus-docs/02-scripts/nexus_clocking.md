# Nexus Clocking

> A multi-job time-clock (shift tracking) system built around a physical clock-in terminal NUI, with per-job NPC terminals created live from an in-game admin panel, a boss panel with per-employee analytics, and a full session history stored in MySQL.

**Version:** N/A · **Status:** In development

---

## 📝 Description

> ⚠️ **This script is still in active development.** The feature set, configuration and Developer API described below are a preview of the intended design and are subject to change before release. Full documentation will be published once the script reaches a stable release.

`nexus_clocking` is planned as a multi-job shift-tracking system: employees clock in and out at a physical terminal (NUI), supervisors create and place per-job terminals live from an in-game admin panel (in the same spirit as `nexus_garage`'s live editor), and a boss panel surfaces per-employee analytics drawn from a full session history kept in MySQL.

More information will be shared as development progresses.
