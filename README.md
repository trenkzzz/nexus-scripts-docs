# Welcome to Nexus Scripts's Docs

Welcome to the official **Nexus Scripts** documentation. Here you will find everything you need to install, configure and get the most out of our scripts for FiveM.

Nexus Scripts was created with a clear goal: to offer **modular**, **compatible** and **well-optimized** resources for ESX and QBCore servers, with a clean user interface designed to make your server stand out.

### Where do I start?

* [**General Requirements**](nexus-docs/01-general-information/requisitos.md): make sure your server meets the minimum requirements before installing any script.
* [**Installation & Compatibility**](nexus-docs/01-general-information/instalacion.md): how to install a script and choose the systems you want it to work with (notifications, text prompts, keys and more).
* [**Script List**](nexus-docs/02-scripts/): the documentation of each script.

### Escrow and protection

Nexus Scripts are protected by the official FiveM escrow system (cfx.re). The protected source code is not directly accessible, but most of the behavior can be customized through the files that are always left unencrypted: `config.lua`, `functions.lua`, `locales.lua` and the interface files of each script.

### About Nexus Scripts

We build scripts designed to last: modular, easy to configure and compatible with the most widely used systems in the community (ESX, QBCore, notification systems, text prompts, vehicle keys and more), so they fit into your server without friction.
