# Support

## How to ask for help

Official support is managed through the store's Discord. Before opening a ticket, make sure you have gone through the following:

1. The script's documentation page.
2. The [Frequently Asked Questions](faq.md) page.
3. The script folder has its original name, `nexus_scriptname`.

If the problem persists, open a ticket with this information:

* Exact name and version of the script.
* Framework used (ESX or QBCore).
* Any console or F8 errors, preferably as a screenshot.
* Steps to reproduce the issue.

{% hint style="info" %}
The more information you provide when opening a ticket, the faster we can help you.
{% endhint %}

## Support schedule

Support is handled directly by the Nexus Scripts team. Response time depends on the workload and the time of day or year.

## What is not included in support

* Errors caused by incorrect modifications of the original resource.
* Incompatibilities with third-party systems.
* General server configuration unrelated to our scripts.
* Problems with free scripts.
